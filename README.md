# Homework OOP

Проект посвящен изучению и практике Объектно-Ориентированного Программирования (ООП) в Python. 
В рамках задания реализованы классы для работы с категориями и продуктами, 
а также написаны unit-тесты с использованием `pytest`.

## Структура проекта

```text
Homework_OOP/
├── data/
│   └── products.json      # Файл с тестовыми данными (категории и продукты)
├── src/
│   ├── __init__.py
│   ├── category.py        # Класс Category (категория товаров)
│   ├── product.py         # Класс Product (описание товара)
│   └── utils.py           # Вспомогательные функции (чтение JSON, создание объектов)
├── tests/
│   ├── __init__.py
│   ├── conftest.py        # Фикстуры для тестов
│   ├── test_category.py   # Тесты для класса Category
│   └── test_product.py    # Тесты для класса Product
├── .gitignore
├── pyproject.toml         # Конфигурация проекта (Poetry)
├── README.md
└── poetry.lock
```

## Реализованный функционал
### Классы (папка src/)
- **`Product`**: Класс для хранения информации о товаре.
    - Атрибуты: `name`, `description`, `quantity`.
    - Приватный атрибут: `__price` (цена).
    - Геттер price — возвращает значение цены. 
    - Сеттер price — устанавливает цену с проверкой: если цена ≤ 0, выводит сообщение "Цена не должна быть нулевая или отрицательная" и не меняет значение.
    - Класс-метод new_product(product_dict) — создаёт объект Product из словаря.
- **`Category`**: Класс для группировки товаров.
    - Атрибуты: `name`, `description`.
    - Приватный атрибут: `__products` (список товаров).
    - Метод add_product(product) — добавляет продукт в приватный список и увеличивает класс-атрибут product_count.
    - Геттер products — возвращает строку со списком всех продуктов в формате:
"Название продукта, X руб. Остаток: X шт.\n".

Классовые атрибуты: category_count (общее кол-во категорий), products_count (общее кол-во товаров во всех категориях).

- **`utils.py`**: Содержит функции:
    - `read_json(path)` — чтение данных из JSON-файла.
    - `create_category_from_json(data)` — преобразование словаря из JSON в объекты классов Category и Product.

### Новое в этой версии (Homework 16.1)
- **Классы-наследники `Product`**:
  - `Smartphone` — смартфон (атрибуты: `efficiency`, `model`, `memory`, `color`).
  - `LawnGrass` — трава газонная (атрибуты: `country`, `germination_period`, `color`).
- **Ограничение сложения**: `Product.__add__` теперь проверяет, что типы товаров совпадают (через `type()`). При попытке сложить разные типы выбрасывается `TypeError`.
- **Ограничение добавления**: `Category.add_product` проверяет, что добавляемый объект является `Product` или его наследником (через `isinstance()`). Иначе — `TypeError`.

### Новое в этой версии (Homework 15.1)
- **`Product.__str__`** — строковое представление: `"Название, X руб. Остаток: X шт."`.
- **`Product.__add__`** — сложение двух продуктов (сумма произведений цены на количество).
- **`Category.__str__`** — строковое представление: `"Название, количество продуктов: X шт."`.
- **`Category.products`** — геттер оптимизирован, использует `Product.__str__`.
- **`CategoryIterator`** — итератор для перебора товаров категории.

### Тестирование (папка tests/)
Проект покрыт тестами с использованием фреймворка pytest.
Для изоляции тестов используются фикстуры (в `conftest.py`), чтобы тесты не зависели друг от друга и от реального 
файла `products.json`.

## Установка и запуск
Для работы с проектом используется пакетный менеджер Poetry.

Убедитесь, что у вас установлен Python 3.14 и Poetry.

Установите зависимости:
```bash
poetry install
```
Активируйте виртуальное окружение:
```bash
poetry shell
```
Запуск основного скрипта.
Чтобы проверить работу функций чтения из JSON и создания объектов, запустите модуль utils.py:

```bash
python -m src.utils
```

(или просто запустите файл utils.py из PyCharm)

Запуск тестов
Для проверки корректности написанного кода запустите pytest:

```bash
poetry run pytest
```
Или для подробного вывода (с названиями тестов):

```bash
poetry run pytest -v
```
